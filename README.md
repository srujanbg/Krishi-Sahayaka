# 🌿 Krishi Sahayaka — Karnataka Farmer Assistant

**ಕೃಷಿ ಸಹಾಯಕ** — a free, bilingual (English + ಕನ್ನಡ) farmer assistant for Karnataka.
Single self-contained web app — no login, no install, works offline.

🔗 **Live:** https://srujanbg.github.io/Krishi-Sahayaka/

## ✨ Features
- **📍 Location** — all **31 districts** and **235 taluks** with automatic District → Taluk
  cascade. Hobli & Village are free-text (type any spelling).
- **🌾 27 crops** — cereals, pulses, oilseeds, commercial & horticulture crops of Karnataka.
- **🩺 Crop Doctor** — take/upload a leaf photo; on-device colour analysis suggests the likely
  disease with organic + chemical remedies and dosage scaled to land size.
- **🌦️ Weather · 💰 Market (best place to sell) · 🌱 Advisory · 🧮 Fertilizer · 🏛️ Schemes · 📞 Help**
- **🔊 Text-to-speech** (Kannada/English), **🌙 dark mode**, **saved profile**.

## ⚠️ Disclaimer
Unofficial guidance tool. Weather & prices are indicative demo data; Crop Doctor is a
preliminary colour-based screening, not a lab diagnosis. Confirm with official sources
(IMD, APMC, Raitha Samparka Kendra) before applying chemicals.

## 🛣️ Roadmap
Live weather + real mandi prices (data.gov.in Agmarknet); LGD API for village/hobli
auto-suggest; trained crop-disease AI (TensorFlow.js).
